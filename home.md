# usr-wwelsh docs

Hi, I'm William Welsh. I build free, open, offline-first tools, mostly single binaries you can run on your own hardware with no accounts, API keys or cloud. Everything is MIT.

This site gathers the docs for every public [usr-wwelsh](https://github.com/usr-wwelsh) repo. Each project's README and `docs/` folder get pulled in nightly, so it stays in sync with GitHub.

Search is semantic, so you can describe what you want instead of guessing a repo name.

## Try searching for

- `run Hugging Face models locally on CPU`
- `download music from YouTube and stream it on my phone`
- `status badge showing my server's CPU and RAM`
- `build a Doom-style game in the browser without code`
- `does hostile feedback make an LLM worse at reasoning`
- `summaries of new arXiv papers without an API key`
- `summarize my GitHub commits with an LLM`
- `run several AI agents in parallel on a kanban board`

## What's here

- **Self-hosting**: run your own AI model server, music streamer, social network and status badges with [turbolab](./turbolab/README.html), [omniMux](./omniMux/README.html), [socialChat](./socialChat/README.html) and [vitalSVG](./vitalSVG/README.html)
- **AI & agents**: orchestrate agents, summarize research papers and test how LLMs behave with [fanoutd](./fanoutd/README.html), [Research-Digest](./Research-Digest/README.html) and [emotional-contamination](./emotional-contamination/README.html)
- **Docs tooling**: [botdocs](./botdocs/README.html) builds this site, and [Dependadocs](./Dependadocs/README.html) flags docs a PR made stale
- **Games & toys**: a no-code Doom-style editor, an ARPG and a 3D museum of GitHub in [Blopple](./Blopple/README.html), [path-of-python](./path-of-python/README.html) and [git-gallery](./git-gallery/README.html)

The sidebar has everything else.
